# Preguntas · tronco
`[perfil]` = lo cubre el perfil (`perfil.md`); se salta si el usuario lo aceptó. Salta todo lo ya respondido.

## A · Tronco
- Nombre, `mod_id`, idea en 1 frase, tamaño v1 (MVP · mediano · completo).
- Mod de referencia (solo configuración, nunca mecánicas): ver SKILL.md paso 4.
- Nombre de la carpeta: `<mod_id>` · `<Nombre Visible>` · otro.
- [perfil] loader, versión de Minecraft, launcher e instancia de prueba, autor/licencia, idiomas, Git.
- Dificultad: igual a vanilla · más difícil · configurable.
- Entorno: solo · servidor con amigos · modpack/público (→ cuidar rendimiento y config).
- ¿Integración con otros mods? (lista las carpetas de mods del directorio de trabajo, si hay).
